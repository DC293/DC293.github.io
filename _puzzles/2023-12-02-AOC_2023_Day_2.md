## Intro
The [Advent of Code](https://adventofcode.com/2023) is a yearly series of puzzles run during the month of December. The daily puzzles are the same for all players but puzzle inputs are randomly generated for each user account (to stop cheating!). The solutions outlined in this blog series are designed to intake any puzzle input and output the correct answer. 

## Part 1
For todays puzzle, we are given a series of games. Each game is made up of several rounds where coloured cubes (red, green or blue) are drawn from a bag. We are given the number of cubes of each colour that are drawn in every round (e.g. 2 red, 3 green, 4 blue). To begin, we must determine which of the games is compatible with a hypothetical bag, containing 12 red, 13 green and 14 green cubes. Our puzzle answer will be the sum of the game ID's of the compatible games.

First, we will process the puzzle input put it into a format thats easier for us to format. Our function takes in the puzzle and a list of colours of the cubes, this gives us versatility if different coloured cubes are used. The output will be a 3D list with the structure: games, rounds, results. 

We start by splitting each match string into their individual rounds, then we will use a nifty library called re to pick out the number of each coloured cube. The re library contains powerful regular expression (RegEx) tools which are usful when dealing with strings. To learn more about RegEx, take a look at the [documentation](https://docs.python.org/3/library/re.html) and have a practice [here](https://regexr.com/). 

```python
import re

def process_puzzle(puzzle, colours):
    puzzle_processed = []
    for i in range(puzzle.count("Game")):
        game_result = []
        for round in puzzle.split("\n")[i].split(";"):
            round_result = []
            for colour in colours:
                if colour in round:
                    colour_index = re.search(r'(\d+)\s+'+colour, round)
                    num = int(colour_index.group(1))
                else: 
                    num = 0 
                round_result.append(num)
            game_result.append(round_result)
        puzzle_processed.append(game_result)
    return puzzle_processed
```

Now we have a formatted puzzle, we can easily loop through each game to see which ones were possible. 
```python
def games_possible(puzzle, red, green, blue):
    possible_games_sum = 0
    for game_no in range(len(puzzle)):
        for match_no in range(len(puzzle[game_no])):
            game_possible = True
            if puzzle[game_no][match_no][0] > red:
                game_possible = False
                break
            elif puzzle[game_no][match_no][1] > green:
                game_possible = False
                break
            elif puzzle[game_no][match_no][2] > blue:
                game_possible = False
                break
        if game_possible:
            possible_games_sum += game_no+1
    return possible_games_sum
```
Running our formatted puzzle through our new function gives us the answer to part 1

## Part 2
For the second part of the puzzle, we must find the fewest number of cubes needed for each game. Our puzzle answer is the sum of the minimum cubes for each game multiplied together. Using our formatted puzzle, we can loop through each game and pick out the maximum before multipliying them together. 

```python
def fewest_cubes(puzzle):
    total = 0
    for game_no in range(len(puzzle)):
        red = 0
        green = 0
        blue = 0
        for match_no in range(len(puzzle[game_no])):
            if puzzle[game_no][match_no][0] > red:
                red = puzzle[game_no][match_no][0]
            if puzzle[game_no][match_no][1] > green:
                green = puzzle[game_no][match_no][1]
            if puzzle[game_no][match_no][2] > blue:
                blue = puzzle[game_no][match_no][2]
        total += red*green*blue
    return total

part_2_result = fewest_cubes(formatted_puzzle)
print(part_2_result)
```
