## Intro
The [Advent of Code](https://adventofcode.com/2023) is a yearly series of puzzles run during the month of December. The daily puzzles are the same for all players but puzzle inputs are randomly generated for each user account (to stop cheating!). The solutions outlined in this blog series are designed to intake any puzzle input and output the correct answer. 

## Part 1
Today we are given a puzzle where each row represents a scratch card with winning numbers and scratched numbers seperated by a '|'. We need to determine the number of winners on each card. Starting at 1 point for 1 winner, each subsequent missing number on the card doubles the points. The final answer is the sum of all points.

Card 1: 13 32 20 16 61 | 61 30 68 82 17 32 24 19
Card 2:  1 21 53 59 44 | 69 82 63 72 16 21 44  1
Card 3: 41 92 73 84 69 | 59 84 76 51 58  5 54 83

Card 1 has two winning numbers (32 and 61), so it is worth 2 points.
Card 2 has two winning numbers (1, 21 and 44), so it is worth 4 points.
Card 3 has one winning number (84), so it is worth 1 point.

Our solution starts by creating empty dictionaries for the winning numbers and the scratched numbers with the dictionary keys set to the card numbers. We then loop around each card, filling the values with the winning numbers and scratched numbers. It's then a simple case of looping through the winning numbers and seeing if they are in our scratched numbers. If they are, we add to our iterator to make sure we calculate the right number of points. 

```python
def check_winners(puzzle):
    winning_nums = {}
    my_nums = {}
    total_points = 0
    
    for card_num in range(1, puzzle.count("Card")+1):
        winning_nums[card_num] = [int(i) for i in puzzle.split("\n")[card_num-1].split("|")[0].split(":")[1].strip().split(" ") if i.isdigit()] 
        my_nums[card_num] = [int(i) for i in puzzle.split("\n")[card_num-1].split("|")[1].strip().split(" ") if i.isdigit()]

        iterator = 0
        card_total = -1
        for num in winning_nums[card_num]:
            if num in my_nums[card_num]:
                iterator += 1
                card_total += 1
        if card_total >= 0:
            total_points += 2**card_total
    
    return total_points

print(check_winners(puzzle))
```

```python
21138
```

## Part 2
In part 2, the scoring method from the previous section has been scrappedchanged. We must instead, count the number of scratchcards given the following rule:

> Specifically, you win copies of the scratchcards below the winning card equal to the number of matches. So, if card 10 were to have 5 matching numbers, you would win one copy each of cards 11, 12, 13, 14, and 15.
> Copies of scratchcards are scored like normal scratchcards and have the same card number as the card they copied. So, if you win a copy of card 10 and it has 5 matching numbers, it would then win a copy of the same cards that the original card 10 won: cards 11, 12, 13, 14, and 15. This process repeats until none of the copies cause you to win any more cards (Cards will never make you copy a card past the end of the table.)

We can change our function slightly to create an additional dictionary to count the number of each card we win. As we enter our loop to count the number of winners for each card, we add to the values in our cards_won dictionary. Once we have finished looping through all the cards, we can output this dictionary and sum up all the values to get our answer. 

```python
def check_winners(puzzle):
    winning_nums = {}
    my_nums = {}
    cards_won = {key:1 for key in range(1, puzzle.count("Card")+1)}
    total_points = 0
    
    for card_num in range(1, puzzle.count("Card")+1):
        winning_nums[card_num] = [int(i) for i in puzzle.split("\n")[card_num-1].split("|")[0].split(":")[1].strip().split(" ") if i.isdigit()] 
        my_nums[card_num] = [int(i) for i in puzzle.split("\n")[card_num-1].split("|")[1].strip().split(" ") if i.isdigit()]

        card_total = -1
        iterator = 0
        for num in winning_nums[card_num]:
            if num in my_nums[card_num]:
                card_total += 1
                iterator += 1
                cards_won[card_num+iterator] += 1*cards_won[card_num]
        if card_total >= 0:
            total_points += 2**card_total
    
    return total_points, cards_won

(total_points, cards_won) = check_winners(puzzle)
print(sum(cards_won.values()))
```

```python
7185540
```
