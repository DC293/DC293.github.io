## Intro
The [Advent of Code](https://adventofcode.com/2023) is a yearly series of puzzles run during the month of December. The daily puzzles are the same for all players but puzzle inputs are randomly generated for each user account (to stop cheating!). The solutions outlined in this blog series are designed to intake any puzzle input and output the correct answer. 


## Part 1
We are given a puzzle containing lines of periods, symbols and numbers. For the first task, we must identify numbers touching symbols, including those in the lines above and below, and on the diagonal. This is best understood when visualised. In the example puzzle section (Figure 1), we would identify:
  - 26 (Line 1)
  - 315 (Line 2)
  - 66 (Line 5)
  - 4 (Line 6)
  - 7 (Line 7)

Numbers 8 (Line 4) and 35 (Line 7) are ignored as they are not adjacent to any symbols. Our answer is the sum of all the numbers touching symbols: 418.

Before we begin solving, we will first format the puzzle to make it easier to iterate through. Firstly, we will add a line of only periods at the beginning and end of the puzzle. This makes it easier to process the edges of the puzzle so we dont have to treat them differently to the processing of the lines in the middle of the puzzle. Once we have doen this, we will split the puzzle into blocks of 3 lines, with each block progessing one line further down the puzzle. This means we can process each block as a mini puzzle segment before adding up the totals at the end. By printing the first two blocks, we can see that a) the first bloc contains a padded row of '.' and b) the puzzle moves down one row in the second block.

We will loop through each block in our puzzle and identify the symbols in the middle line using our friend [re](https://docs.python.org/3/library/re.html). For each symbol we return the range of indexes of the symbol, plus one before and after. This provides us with all the index positions where numbers could be adjacent. Using re once more, we identify all the numbers and their indexes for each line in the bloc. Finally, its a case of checking the index lists of the symbols and numbers to see if there is any overlap. If there is, we add it to the total. 

```python
import re

def part_numbers(puzzle):
    def find_touching_numbers(symbols, numbers):
        result = 0
        for symbol_indexes, symbol in symbols:
            for number_indexes, number in numbers:
                if any(item in number_indexes for item in symbol_indexes):
                    result += int(number)
        return result
    
    puzzle_answer = 0
    for lines in puzzle:
        symbols = [(list(range(match.start()-1, match.start()+2)), match.group()) for match in re.finditer(r'[^\w\.]', lines[1])]
        
        numbers_1 = [(list(range(match.start(), match.end())), match.group()) for match in re.finditer(r'\d+', lines[0])]
        numbers_2 = [(list(range(match.start(), match.end())), match.group()) for match in re.finditer(r'\d+', lines[1])]
        numbers_3 = [(list(range(match.start(), match.end())), match.group()) for match in re.finditer(r'\d+', lines[2])]
        
        puzzle_answer += find_touching_numbers(symbols, numbers_1)
        puzzle_answer += find_touching_numbers(symbols, numbers_2)
        puzzle_answer += find_touching_numbers(symbols, numbers_3)

    return puzzle_answer
```

## Part 2
In the second part of the puzzle, we are tasked with only identifying the numbers adjacent to gear '*' symbols. Gears which have exactly two adjacent numbers must be multiplied together. The puzzle solution is all the gear multiples summed together. In our example puzzle (Figure 1), we would multiply 66 (Line 5) and 4 (Line 6). We ignore 9 (Line 4) as only one number is adjacent to the gear.

We will use a similar function to part one with some adjustments. Firstly, we will instruct re to only identify the gears as symbols. We have also replaced our find_touching_numbers function with a find_gear_ratios function which only takes one symbol index at a time. This is important as we only want to identiy connected to one specific gear rather than returning all the numbers touching all teh gears identified in the puzzle bloc. Before calculating the product of the gear, we check to see that only two numbers were touching. If True, we multiply the numbers togther and add it to the total.
